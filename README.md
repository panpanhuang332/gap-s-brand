# 台新新光金控 × Gap-S｜單頁 3D 研究型簡報

**合併之後，信任如何成立？**  
以 Gap-S 視角分析台新新光金控的品牌整合

## 直接使用

解壓縮後，以電腦的一般瀏覽器開啟 `index.html`。這是完整單檔網頁，HTML、CSS、JavaScript 與內容都在同一檔案內。無須安裝 Node.js、套件、字型、登入帳號或連網。只有點選「官方來源」外部連結時需要網路。

點「開始發表」啟動計時並嘗試進入全螢幕；使用方向鍵、空白鍵或簡報筆切段。計時不控制動畫，也不會在十分鐘自動停止。第一次使用，先將九段走完一次並依自己的語速彩排。

手機可按底部左右鍵或左右滑動；直向採響應式重排，必要時可捲動中央內容。正式投影使用電腦較合適。部分手機的檔案預覽器不執行 JavaScript，請使用一般瀏覽器；無法直接開啟本機 HTML 的裝置，需經靜態網頁主機存取。

**本交付檔案不是已部署的公開網站。** 本包沒有變更任何 GitHub 儲存庫，也未對外發布原稿。

## 發表安排

九段：研究起點 → 品牌整合 → 研究問題 → Gap-S 理論 → 研究方法 → 核心分析 → 品牌意涵 → 管理建議 → 結論與限制。

目標主講9分30秒，預留30秒緩衝；問答另計。完整講稿內建於網頁，也另附 `docs/逐段講者稿.md`。

第六段可點選「實質資本／衡量基礎／過渡安排」三個分析方向；右側另有每四秒切換一次的分析巡覽。底部「動態預覽」每七秒切換一段，僅供快速看動畫，**不是正式發表的語速或十分鐘自動放映**。

## 講者模式

按 `P` 或右上角「講者視窗」可開啟同步的獨立視窗，顯示目前講稿、講述提示、下一段與計時，可直接控制主簡報。若彈出視窗被阻擋，請允許瀏覽器開啟該視窗。

投影時，作業系統請選「延伸螢幕」，將主簡報移到投影幕，講者視窗留在筆電。不要以鏡像模式展示講者稿。

`N` 開啟的是同畫面講稿面板，觀眾也會看見；適合彩排，不適合鏡像投影時偷看稿。

## 技術結構

原生 HTML + CSS 3D + JavaScript。每個立體物件具有六個表面，透過 `perspective`、`preserve-3d` 與座標轉換變換場景。文字與資料留在正面的閱讀層。沒有 Three.js、GSAP、React、CDN 或外部素材依賴。

- `index.html`：完整離線成品。
- `src/template.html`：結構與介面。
- `src/style.css`：視覺、六面立體模型與響應式排版。
- `src/scene.js`：九段幾何姿態、標籤與縮放。
- `src/content.js`：標題、內容、講稿與來源，優先在此修改。
- `src/app.js`：切段、計時、來源面板、講者視窗與快捷鍵。
- `build.mjs`：把來源合成單檔 HTML，不需要 npm install。
- `docs/`：講者稿、內容備份與測試說明。
- `previews/`：實際網頁截圖，不是概念設計稿。
- `tests/`：瀏覽器測試與結果。

修改原始碼後，在專案資料夾使用 Node.js 執行：

```sh
node build.mjs
```

也可以直接修改完整 `index.html`，但日後重建會覆寫它，故建議以 `src/` 作為修改來源。

## 部署

此網站無後端。上傳 `index.html` 到任意可提供靜態 HTML 的主機即可，不需要建置服務、API 金鑰或環境變數。檔案中的官方來源連結不會自動更新資料；日後若調整研究時點，應同時重作內容核對。
